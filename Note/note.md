| 데이터 특성            | 분석 목적            | 분석 방법론                     | 주요 활용             |
| ----------------- | ---------------- | -------------------------- | ----------------- |
| **단일 변수 데이터**     | 데이터 요약 및 분포 파악   | 기술통계분석                     | 평균, 분산, 빈도, 분포 확인 |
| **두 변수 간 관계 분석**  | 변수 간 연관성 확인      | 상관분석                       | 매출-광고비 관계 분석      |
| **범주형 변수 간 관계**   | 집단 간 관련성 확인      | 교차분석(Contingency Analysis) | 성별-상품선호 관계 분석     |
| **구매/행동 패턴 데이터**  | 항목 간 동시 발생 규칙 발견 | 연관분석(Association Analysis) | 장바구니 분석           |
| **집단 간 차이 확인**    | 평균 차이 검증         | t-test, ANOVA              | 남녀 평균 비교          |
| **변수 영향 관계 분석**   | 원인 및 영향력 분석      | 회귀분석                       | 매출 예측             |
| **시간에 따른 변화 데이터** | 추세 및 미래 예측       | 시계열 분석                     | 주가, 판매량 예측        |
| **많은 변수 데이터**     | 차원 축소            | 주성분분석(PCA)                 | 변수 축소             |
| **유사 데이터 그룹화**    | 고객/패턴 분류         | 군집분석                       | 고객 세분화            |
| **범주 예측 데이터**     | 분류               | 판별분석, 로지스틱 회귀              | 고객 이탈 예측          |
